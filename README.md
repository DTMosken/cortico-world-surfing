# 网上冲浪

让 Cortico 阅读网页和B站视频字幕，搜索视频，并根据读到的内容回答问题。发送链接或BV号即可使用，无需登录B站。

## 能做什么

- **阅读网页**：打开你发来的链接或网页搜索结果，提取正文和链接，长文章可以继续读。
- **阅读B站视频**：读取人工或AI字幕，保留时间范围，支持视频分P和 b23.tv 短链。
- **搜索视频**：按关键词查找视频，也可以搜索“关键词 梗知识”来了解梗或概念。

可与 learn 学习扩展配合，将读到的梗或概念交给学习工具记录。

## 使用示例

- “看看BV1h9a26vEzd，讲了什么。”
- “去B站搜一下‘破防 梗知识’，读完解释这个梗。”
- “打开这个网页链接，看看文中的条件。”
- “继续读刚才那篇文章。”

明确要求查找视频并提供关键词时，会搜索候选；仅模糊提到某个视频时不会自动搜索。

## 安装

需要支持 World 扩展 API 5 的 Cortico，以及 Node.js 22.12 以上的22系列或24以上版本。

1. 在 Cortico 扩展管理页安装本项目的本地目录。
2. 重启 Cortico 进程，启用“网上冲浪”。
3. 如需读取依赖脚本加载正文的网页，在扩展目录执行一次：

   ```powershell
   corepack pnpm install:browser
   ```

## 调整阅读量

在“网上冲浪”的配置页调整每次返回量、字幕分组，以及读取和缓存限制。

默认每次返回最多 **4,096 估算 token**，长网页和字幕按需分段续读。这个数值控制返回量，与模型的实际计费 token 可能不同；连续续读仍会累积会话上下文。

每份材料默认保留最多 **300,000字符**。达到保留上限时，结果会标明内容不完整。续读内容保存在内存，默认最多保留15分钟；失效或重启后需要重新读取。

## 适用范围

- 网页需通过公开域名访问；不支持账号登录、本机地址或IP地址。正文需要登录或验证码时，可能只能取得页面提示。
- 视频内容来自可访问的字幕。部分视频或分P暂时取不到字幕，无法据此判断视频没有声音。
- 网页阅读支持正文和链接，暂不提取PDF、图片、音频或视频画面。
- 只有标题和封面的QQ分享卡片无法确定来源。可以提供BV号、视频链接，或明确要求按标题在B站搜索。
